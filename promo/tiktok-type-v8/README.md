## 视觉与节奏

画面以汉字为主体，用宣纸白、朱红、墨绿、暖金和黑体／宋体／毛笔字组织节奏。

| 成片时间 | 文字动效 |
| --- | --- |
| 0–2.92 秒 | “叮叮当”像算盘珠落下，横杆收拢成“算盘响” |
| 2.92–6.10 秒 | “山海伙伴”从四向聚拢，“来帮忙”落位 |
| 6.10–8.98 秒 | 斜向分屏，“你当掌柜／我来跑堂”呼应 |
| 8.98–12.56 秒 | “小小客栈”收缩，巨大的“大”字撑开画面 |
| 12.56–15.68 秒 | “来”字旋转字阵，三个“坐”逐个落座 |
| 15.68–20.00 秒 | “一桌烟火”展开，“热热闹闹”拼成四色字块 |
| 20.00–22.02 秒 | 两次“开张”左右开合，朱红／宣纸白反转 |
| 22.02–27.00 秒 | 毛笔字标题汇合，“等你当家”逐字落位并停留 |

55 个歌词字的时间点以原录音的本地语音识别结果为基础，使用用户提供的歌词修正同音字。动画提前约 75 ms 起势，并随实际音频瞬态轻微弹动；没有强制套用音乐提示词中的 BPM。浏览器预览以音频播放进度作为动画时钟；导出逐帧使用同一时间线。

音乐保留原速、原调；起点做 18 ms 淡入，末尾 700 ms 淡出。音频只剪取这一段，不叠加新配乐或音效。

## 工程与复现

`source/` 包含 HTML、Canvas 动画、字体、音乐选段、逐字时间线及导出脚本。`score.json` 记录绝对／相对时间点与原音频 SHA-256。`timeline.js` 是供离线浏览器直接读取的数据版本。

需要 Node.js、Playwright、Chromium、Python 3 和 FFmpeg。已在 Node 24、Playwright 1.62.1、Chromium 151、FFmpeg 7.1.5 环境导出。

```bash
cd source
npm install
# 如系统未安装 Chromium，可使用 npx playwright install chromium，
# 并通过 CHROMIUM_PATH 指定该浏览器可执行文件。
node render.cjs --stills
python3 build_preview.py
node render.cjs
node verify.cjs
```

默认浏览器位置 `/usr/bin/chromium`；可用 `CHROMIUM_PATH` 修改。也可用 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright 模块。

源工程 `index.html` 需通过本地静态服务器访问；直接双击请使用交付根目录的 `preview-standalone.html`。
